# Ocupação de Salas INOVALAB

PWA público com indicadores de ocupação dos quatro espaços do INOVALAB.

## Conteúdo

- `google-apps-script/`: backend e interface originais.
- `app/`: aplicação pública e proxy de dados.
- `public/`: interface preservada, manifesto, favicon e ícones.

## Validação

```bash
pnpm test
```
